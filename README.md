Project Overview
​"For my individual project, I built a Password Strength Evaluator using Python in VS Code, and published the complete code repository on GitHub."
​Key Features & How It Works
​Real-time Rules Engine: Uses regular expressions (re) to analyze user-input passwords against standard security criteria.
​5-Point Validation Checks:
​Minimum length (at least 8 characters).
​Uppercase letters (A-Z).
​Lowercase letters (a-z).
​Numbers (0-9).
​Special characters (@$!%*?&).
​Dynamic Feedback & Scoring: Categorizes password strength from Weak to Extremely Strong and provides specific, actionable recommendations on what missing character types to add.
​Technical Stack & Deliverables
​Language & Tools: Built using Python 3 and developed inside VS Code.
​Version Control: Managed and deployed to GitHub using Git commands (git init, commit, and push).
​Documentation: Includes a structured README.md file covering setup, execution steps, and feature details.
